# 静子叶片压力中心计算（基于表面压力点云）

从两个纯文本的表面压力数据文件，计算静子叶片的气动合力与**压力中心**（压力作用中心）：

* `ps` = 压力面（pressure side），`ss` = 吸力面（suction side）
* 每行 4 列：`x  y  z  p`，其中 x,y,z 单位 [m]，p 单位 [Pa]
* 每个文件约 1 万行散点（随附的 `srv_ps.dat` / `srv_ss.dat` 各只有 1 行，
  仅用于展示格式）。点云本身就是叶片叶形——**不需要额外的叶形数据**。

## 环境要求（Windows 7）

* **Python 3.8.10**：Windows 7 官方支持的最后一个 Python，用它的 Windows
  安装包。3.9+ 不再支持 Windows 7。
* **NumPy 1.22.4 + SciPy 1.8.1**（已在 `requirements.txt` 钉死）：更新的版本会
  放弃 Windows 7 运行时支持，务必用这两个版本。
* 需装好 **UCRT**（通用 C 运行时），即 Windows 更新 KB2999226；多数 Win7 已自带。
* 代码本身只用 NumPy/SciPy 的基础 API，3.8 语法兼容，无 3.9+ 特性。

> 在 Linux / macOS 上开发时，可用系统自带较新的 Python + 较新 NumPy/SciPy
> 跑测试；部署到 Windows 7 时再用上面的 3.8.10 + 钉死版本。

## 运行方式（Windows 7）

物理机上**不用虚拟环境**（虚拟环境仅开发时用）。在程序所在目录打开 `cmd`，
直接把依赖装进系统 Python 3.8.10：

```bat
:: 装依赖到系统 Python 3.8.10（一次性）
python -m pip install -r requirements.txt

:: 跑程序（默认按绝对压力处理；输出坐标系默认结构系 mech，位置 mm）
python pressure_center.py srv_ps.dat srv_ss.dat
:: 双面结构（叶片/机翼上下）直接两文件；单面或闭合体：省略 ss + --inside-point
python pressure_center.py wing_skin.dat --inside-point 0.1 -0.05 0.15
:: 指定输出坐标系：mech(结构系,mm,默认) 或 aero(气动系,m)
python pressure_center.py srv_ps.dat srv_ss.dat --cstype aero
:: 可选：换算到表压基准（减去参考压 p_ref；如闭合体近似、或与同事对齐参考压）：
python pressure_center.py srv_ps.dat srv_ss.dat --pref 101325
```

> `--cstype` 仅影响**显示**：内部计算始终在气动系(m)进行。**注意 mech 与 aero
> 不只是单位不同（mm vs m），坐标轴也不同**：
> `aero = R·mech`，`R=[[0,0,1],[0,-1,0],[1,0,0]]`（x↔z 互换、y 取反），位置再
> /1000 (mm→m)；力/力矩只做旋转 R，单位 N、N·m 不变。

> `python` 必须指向 3.8.10。若机器上装了多个 Python，用 `py -3.8` 或写全路径。
>
> 开发时（Linux/macOS 或本机调试）若想隔离环境，可：
> `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt`，
> 然后 `.venv/bin/python pressure_center.py ...`。但生产物理机无需此步。

## 物理（简述）

面元上压力沿**向外**单位法向 **n** 作用，对叶片的微力指向内部：

```
dF = -p * n * dA,        F = -∮ p n dA,        M = ∮ (r-r0) × dF
```

**三维的关键细节（重要）**：合力矩为零的点的集合，在三维下一般是一条
*线*（合力的作用线），而**不是一个唯一的点**。而且，一般的二维分布会留下
一个沿 **F** 方向、**无法通过选点消除的剩余力偶**（绕力轴的纯扭矩）。
因此本程序给出：

* `F = (Fx, Fy, Fz)` 与 `|F|` —— 气动合力；
* **作用线**（线上一点 + 单位方向 `F_hat`）；
* **压力中心点** = 作用线上**距叶片本体质心最近**的点（落在叶片上/附近，
  物理上更有意义——用坐标原点会显得任意）；
* **剩余力偶** `M_res = (M·F_hat) F_hat`（与参考点无关）。若 `|M_res| ≈ 0`，
  说明载荷可化为一个单纯的单力，所报点即真正的零力矩点；否则会提示存在
  一个绕力轴的小扭矩。

## 数值方法

对每个面（ps / ss）：先用 PCA 找到最佳拟合平面，把点投影到该平面后做
二维 Delaunay 三角化，再把三角形还原到三维。每个三角形：
`area = 0.5|e1×e2|`，`n = (e1×e2)/|e1×e2|`。力与力矩都用**三点边中点
积分**（对二次多项式精确），因此对任何在扁平三角形上线性的压力场，力
（线性 p）和力矩（线性 r × 线性 p，即二次被积函数）都能**精确积分**。

外法向按**整面**统一取向：让每个面的法向指向**另一个面质心的反方向**
（用的是厚度方向，对弯度稳健——若用本体质心启发式，弯度峰值附近的压力面
三角形法向会被翻成向内）。Delaunay 在凹边界处（弯的前/后缘）会向凸包外
“长出”真实叶形之外的伪三角形，多算面积和压力；用**边长过滤 + 外接圆半径
（alpha-shape）过滤**双重剔除，比单一边长过滤更尊重弯曲/凹边界。

## 验算（生产环境）

用 `verify.py` 拿“已知积分点的外部载荷”（某点处的 F 与 M）验算程序结果是否
一致。**结果输出到同目录 `verify_report.md`**（markdown 文件，不在终端刷长
报告——Windows cmd 显示更清爽）；终端只打印简短摘要（每项 PASS/FAIL + 整体
结果）。可用 `--out` 改输出文件名。

外部载荷文件 `external_load.txt` 为**行格式**（每行一个值，可带 `#` 注释）。
随附的 `external_load.sample.txt` 是**模板**（占位 0，仅示意格式）；生产环境复制
为 `external_load.txt` 并把 9 个值替换为实际数据——叶片几何与力幅都由你的
`.dat` 文件本身给出，程序不预设任何载荷：

```
mech              #cs_type: aero(气动系,位置 m) 或 mech(结构系,位置 mm)
<x>               #参考点 r_ref 的 x（mech 时 mm，aero 时 m）
<y>               #参考点 r_ref 的 y
<z>               #参考点 r_ref 的 z
<Fx>              #合力 Fx [N]
<Fy>              #合力 Fy [N]
<Fz>              #合力 Fz [N]
<mx>              #弯矩 mx [N·m]
<my>              #弯矩 my [N·m]
<mz>              #弯矩 mz [N·m]
```

```bat
python verify.py --ps srv_ps.dat --ss srv_ss.dat --ext external_load.txt --tol 1e-3
```

**坐标系**：在文件第一行用 `aero` 或 `mech` 指定。`mech`（结构系，
mm）与气动系（m）的关系是 `aero = (mech_z, -mech_y, mech_x)/1000`（x、z 互换，
y 取反）。程序内部仍按气动系(m)计算，但**输入与输出分析都按你指定的坐标系
显示**（结构系：位置 mm、力/力矩旋转；气动系：不变）。力/力矩单位不变（N、
N·m），仅位置在结构系用 mm。注意外部 `mx,my,mz` 必须是右手系 `M=∮(r-r_ref)×dF`。

**误差分析全部数据驱动**：归一尺度直接来自 `.dat` 文件——特征长度 `L` = 点云
各轴跨度的最大值（叶片最大尺寸），力矩尺度 `|F|·L`。四项误差（合力、力矩、
压力中心、剩余力偶）都按这些尺度归一为**相对误差**（以百分比显示），`--tol`
即相对容差（默认 1e-3 = 0.1%）。这样阈值与坐标系/单位无关，也不依赖任何预设
载荷；同时仍打印绝对差，便于直观判断。

原理：合力与参考点无关直接比；力矩用 `M_A = M_B + (B-A)×F` 在外部点与本体质心
间换算后比；压力中心按同一“最近本体质心”约定由外部 F、M 重算后比。

`verify.py` 还会把外部弯矩 **分解为「沿力 / 垂直力」两部分**并换算成位置单位：
沿力分量 = 不可消除的剩余力偶（真扭矩，挪点消不掉，是物理量）；
垂直力分量 / |F| = 当 r_ref 取程序压力中心点时，才是同事作用线相对程序 cp 的
**位置误差**。所以判断“那点弯矩是真扭矩还是误差”，看分解结果即可，不用瞎猜。

## 开发过程验证（非生产）

以下三个脚本**仅用于开发期自检/调试**，生产环境不需要运行：

```bat
python dev/test_pressure_center.py   :: 4 个解析算例，达到机器精度
python dev/demo_realistic.py          :: 1万点/面 的弯叶片冒烟测试 + 计时
python verify.py --selftest           :: 验算脚本自身转移公式自洽（自包含）
```

- `dev/test_pressure_center.py`：四个解析算例（常压 / 线性压力，平板 / 倾斜 / 散点
  网格）相对误差都在 ~1e-13 量级——因为三点积分对扁平三角形上的线性压力是
  精确的。
- `dev/demo_realistic.py`：生成真实规模弯叶片跑全流程，确认性能（约 0.1 秒）与
  数值合理。
- `verify.py --selftest`：用内嵌小叶片反推外部载荷再喂回，验证力矩转移
  公式与坐标转换自洽（机器精度）；自包含，不依赖 `dev/` 下文件。

## 假设 / 局限

* 每个面片是其最佳拟合平面上的“图”（不发生折叠）；对常规叶片的吸力面/
  压力面成立。
* 两个面片彼此分开（有限厚度），外法向才有明确定义；若两面重合，回退到
  本体质心启发式。
* 压力默认按**绝对压力**处理（直接用原始 p，不减）。若要表压基准（如闭合体
  近似、或与同事对齐参考压），用 `--pref P_REF` 减去参考压。对薄叶片，常数
  （环境）压力部分在 ps 与 ss 间近似抵消，故绝对压力下合力也基本正确；压力
  中心与小幅残差可能略受影响。
